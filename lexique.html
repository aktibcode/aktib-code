Le lexique

Les mots de la tech, définis.

Pas de définitions circulaires ni de sigles qui renvoient à d’autres sigles. Une notion, une explication, et si vous voulez creuser : l’article correspondant.

20 notions

A

Algorithme

Suite d’étapes précises pour résoudre un problème. Une recette de cuisine est un algorithme ; un programme est un algorithme écrit pour une machine.
Lire l’article

Fondamentaux

API

Contrat qui permet à deux logiciels de communiquer : une adresse, un format de données et des règles d’accès. Pensez à une prise électrique standardisée.
Lire l’article

Développement

B

Base de données

Système qui stocke des informations structurées et garantit leur cohérence, même quand plusieurs personnes les consultent ou les modifient en même temps.
Lire l’article

Fondamentaux

C

Cache

Copie temporaire de données conservée pour répondre plus vite. Le cache évite de refaire un calcul ou un téléchargement déjà effectué.
Lire l’article

Web

Centre de données

Bâtiment rempli de serveurs, alimenté en électricité et refroidi en permanence. C’est l’infrastructure physique derrière le « cloud ».
Lire l’article

Infrastructure

Chiffrement

Transformation d’un message en contenu illisible sans la clé. Le chiffrement protège la confidentialité ; il ne garantit pas l’honnêteté de l’émetteur.
Lire l’article

Sécurité

Cloud

Location de ressources informatiques (serveurs, stockage, logiciels) accessibles par réseau. Le cloud est l’informatique de quelqu’un d’autre, dans un bâtiment réel.
Lire l’article

Infrastructure

Code source

Texte écrit par des humains dans un langage de programmation, qui décrit le fonctionnement d’un logiciel. Il est compilé ou interprété pour être exécuté.
Lire l’article

Développement

Cookie

Petit fichier déposé par un site dans votre navigateur. Il sert à mémoriser une session ou des préférences, et parfois à vous suivre à des fins publicitaires.
Lire l’article

Web

D

DNS

Annuaire d’Internet : il traduit les noms de domaine (aktibcode.com) en adresses IP compréhensibles par les machines.
Lire l’article

Web

H

HTTPS

Version chiffrée et authentifiée du protocole HTTP. Elle protège la conversation entre le navigateur et le serveur au moyen de TLS.
Lire l’article

Sécurité

I

Index

Structure qui trie certaines données pour accélérer les recherches, comme l’index d’un livre. Il accélère les lectures mais alourdit les écritures.
Lire l’article

Fondamentaux

L

Latence

Délai entre une demande et le début de la réponse. Une latence faible donne une impression de réactivité ; elle dépend surtout de la distance et du réseau.
Lire l’article

Infrastructure

LLM

Grand modèle de langage (Large Language Model). Système entraîné à prédire la suite probable d’un texte, ce qui lui permet de rédiger, résumer ou converser.
Lire l’article

Intelligence artificielle

O

Open source

Logiciel dont la licence garantit le droit d’exécuter, d’étudier, de modifier et de redistribuer le code source. Ce n’est pas synonyme de gratuit.
Lire l’article

Culture

P

Phishing

Hameçonnage : message ou site imitant une organisation de confiance pour vous pousser à révéler un mot de passe ou à effectuer un paiement.
Lire l’article

Sécurité

Protocole

Ensemble de règles qui permettent à des machines de communiquer. HTTP, TCP et TLS sont des protocoles aux rôles complémentaires.
Lire l’article

Web

S

Serveur

Ordinateur ou logiciel qui répond à des demandes envoyées par d’autres machines (les clients). Il peut servir des pages web, des fichiers ou des API.
Lire l’article

Infrastructure

T

Token

Petite unité de texte (souvent un morceau de mot) utilisée par les modèles de langage. Le modèle prédit le token suivant, pas la phrase entière.
Lire l’article

Intelligence artificielle

Transaction

Ensemble d’opérations sur une base de données qui réussit entièrement ou est entièrement annulé. Elle empêche les états à moitié mis à jour.
