Le manifeste

Le code n’est pas réservé aux ingénieurs.

La tech façonne nos emplois, nos administrations et nos conversations. La comprendre n’est pas un luxe de spécialiste : c’est une condition pour décider, contester et choisir. Nous croyons à une vulgarisation exigeante — assez simple pour être lue, assez honnête pour ne pas mentir.

Le lexique

Les mots, démystifiés.

API, LLM, token, transaction : une définition courte, une phrase pour comprendre, et l’article pour aller plus loin.

Ouvrir le lexique
API Contrat qui permet à deux logiciels de communiquer : une adresse, un format de données et des règles d’accès. Pensez à une prise électrique standardisée.
Développement
LLM Grand modèle de langage (Large Language Model). Système entraîné à prédire la suite probable d’un texte, ce qui lui permet de rédiger, résumer ou converser.
Intelligence artificielle
HTTPS Version chiffrée et authentifiée du protocole HTTP. Elle protège la conversation entre le navigateur et le serveur au moyen de TLS.
Sécurité
Open source Logiciel dont la licence garantit le droit d’exécuter, d’étudier, de modifier et de redistribuer le code source. Ce n’est pas synonyme de gratuit.
